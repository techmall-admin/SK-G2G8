# SK-G2G8

One-page Total Battle calculator for guard grades G2 to G8.

Enter what you have now (Valor Points, academy, hero, projects, gold, Wolf/Dragon/Forest coins, wood/iron/stone) and the research you finished for your next grade. The page shows what is still missing, how many Ragnarök runs you need, and the road to G8.

Your numbers are saved in your browser (press **Save**, and changes also save automatically).

Open `index.html` in a browser, or publish the repo with GitHub Pages.
